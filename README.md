# 트립알림 ✈️

엑셀로 여행 일정을 올리면 **정해진 시간마다 알려 주는** 여행 도우미 웹사이트예요.
핸드폰에서 쓰기 편하게 만들었고, 데스크톱에서는 사이드바 + 위젯 화면으로 바뀌어요.
디자인은 Figma 파일 [여행 일정 알림 사이트 디자인](https://www.figma.com/design/ji8Vr3gkGuGbms8SOEF9ro)의 손그림(Sketchy Annotations) 테마를 그대로 옮겼어요.

## 기능

- **엑셀 업로드**: `.xlsx` · `.xls` · `.csv`. 열 이름을 자동으로 알아보고, 틀리면 직접 고를 수 있어요.
- **오늘 일정**: 다음 일정과 남은 시간 카운트다운, 날짜별 일정 카드, 일정 상세(지도 · 길찾기 · 메모)
- **알림**: 일정 N분 전에 브라우저 알림 + 화면 알림 + 소리/진동, "5분 뒤 다시" 다시 알림
- **여행 도구**: 현지 시각/시차, 환율 계산기(실시간 환율), 날씨(시간별 강수 확률), 준비물 체크리스트
- **오프라인**: 한 번 열면 서비스 워커가 앱을 저장해서 인터넷이 없어도 일정을 볼 수 있어요.
- 일정 · 준비물 · 설정은 **이 기기 브라우저에만 저장**돼요. 서버로 보내지 않아요.

## 엑셀 양식

첫 줄은 열 이름이에요. 아래 단어가 들어 있으면 자동으로 맞춰요. 사이트의 **양식 다운로드** 버튼으로 예시 파일을 받을 수 있어요.

| 열 | 알아보는 이름 | 예시 값 |
| --- | --- | --- |
| 날짜 | 날짜, 일자, date | `2026-10-26`, `10/26`, `10월 26일`, 엑셀 날짜 |
| 일차 (날짜 대신) | 일차, day | `1`, `2일차` → 설정의 "1일차 날짜"부터 계산 |
| 시간 | 시간, 시각, 시작, time | `09:30`, `오후 2시`, `14시 30분`, 엑셀 시간 |
| 일정 | 일정, 제목, 내용, 활동, title | `루브르 박물관` |
| 장소 (선택) | 장소, 위치, 주소, place | `Rue de Rivoli, 75001 Paris` |
| 메모 (선택) | 메모, 비고, 참고, note | `뮤지엄 패스 지참` |
| 알림 (선택) | 알림, 알람, remind | `10분 전`, `1시간 전`, `정각`, `없음` |
| 종료 (선택) | 종료, 끝, end | `11:30` |

- 시트가 여러 개면 일정을 가장 많이 읽을 수 있는 시트를 자동으로 골라요(업로드 화면에서 바꿀 수 있어요).
- 시간은 `09:00~10:30`처럼 범위로 적어도 돼요. 뒤쪽 시각을 종료 시간으로 써요.
- 연도 없는 날짜(`1/18`)는 두 달 넘게 지난 날이면 내년 날짜로 봐요.
- "구분"(이동·식사·관광 …)과 "지도 URL" 열도 읽어요. 지도 링크가 있으면 지도 버튼이 그 링크로 열려요.
- 같은 날 일정은 날짜를 첫 줄에만 적어도 돼요.
- 시간은 **여행지 현지 시각**으로 계산해요. 여행지는 설정에서 바꿀 수 있어요.

## 알림에 대해 꼭 알아 두세요

- 알림은 **사이트(또는 홈 화면 앱)가 열려 있거나 백그라운드 탭에 있을 때** 울려요. 브라우저를 완전히 닫으면 울리지 않아요.
  닫힌 상태에서도 울리게 하려면 푸시 서버가 필요해요.
- **아이폰**: Safari에서 공유 → **홈 화면에 추가**한 뒤 그 아이콘으로 열어야 알림을 받을 수 있어요(iOS 16.4 이상).
- **안드로이드 크롬**: 처음 알림을 켤 때 권한을 허용해 주세요. 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 로그인 · 기기 간 공유 (Firebase)

설정 탭의 **계정 · 기기 간 공유**에서 이메일과 비밀번호로 가입·로그인하면, 일정 · 경비 · 실제 지출이
Firebase(`travel-6fd2d`)의 `users/<계정 ID>/trips/current` 문서에 저장되고 같은 계정의 모든 기기에 실시간으로 맞춰져요.
알림 설정과 보낸 알림 기록은 기기마다 따로예요. 로그인하지 않으면 지금처럼 그 기기에만 저장돼요.

Firestore 보안 규칙(Firebase 콘솔 → Firestore Database → 규칙):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

Authentication → 설정 → 승인된 도메인에 `john31331234-gif.github.io`가 있어야 해요.

## 아이폰 위젯 (Scriptable)

`widget/trip-widget.js`는 무료 앱 **Scriptable**용 위젯 스크립트예요. 로그인한 계정(Firebase)의 일정을 읽어
홈 화면(작게 · 중간 · 크게)과 잠금 화면에 다음 일정, 남은 시간, 이어지는 일정, 지연·빠듯 표시, 남은 예산을 보여 줘요.

1. 사이트 **설정 → 아이폰 위젯 → 스크립트 복사** (또는 이 파일 내용을 복사)
2. Scriptable → **+** → 붙여 넣기 → 이름 `트립알림` → ▶ 실행 → 사이트와 같은 이메일 · 비밀번호 입력(키체인에 저장)
3. 홈 화면 길게 누르기 → **+** → Scriptable → 크기 선택 → 위젯 편집 → Script: `트립알림`
   (Parameter에 `ticket`을 쓰면 보딩패스 색)

위젯은 iOS가 정한 주기로 새로고침되지만, 남은 시간("20분 후")은 iOS가 직접 계속 갱신해요.
인터넷이 안 되면 마지막으로 받은 일정을 보여 줘요. 위젯은 알림을 울리지 않아요.

## 일정 미리 넣어 두기

`data/preset.json`과 엑셀 파일을 함께 배포하면, 일정이 비어 있는 브라우저에서 열 때 그 엑셀을 자동으로 불러와요.

```json
{ "file": "fukuoka-beppu.xlsx", "city": "fukuoka", "tripName": "후쿠오카 · 벳푸 여행" }
```

개인 일정이 저장소에 올라가지 않도록 `data/` 폴더는 `.gitignore`에 넣어 두었어요.

## 실행하기

빌드 과정이 없는 정적 사이트예요. 아무 정적 서버로 열면 돼요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

서비스 워커와 알림은 `https://` 또는 `localhost`에서만 동작해요. GitHub Pages에 올리면 바로 쓸 수 있어요
(저장소 Settings → Pages → Branch: `main` / `/ (root)` → Save).
켜면 `https://john31331234-gif.github.io/travel/` 에서 열려요.

## 파일 구성

```
index.html            화면 구조와 아이콘
css/style.css         손그림 테마 (Figma 변수와 같은 이름의 색상 토큰)
js/app.js             엑셀 읽기, 일정 계산, 알림, 위젯
sw.js                 오프라인 캐시, 알림 클릭 처리
manifest.webmanifest  홈 화면 앱 설정
vendor/               SheetJS (엑셀 읽기, Apache-2.0)
```

외부 서비스: 환율 [open.er-api.com](https://www.exchangerate-api.com/), 날씨 [Open-Meteo](https://open-meteo.com/), 지도 Google Maps 링크, 글꼴 Google Fonts(Gaegu, Caveat).
